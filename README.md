### About me

I'm a back-end developer specialized in **Java and Spring Boot**, interested in building software that is reliable, easy to understand, and ready to evolve.

My work combines REST API development, persistence, testing, and backend architecture. I enjoy going beyond “it works” by thinking carefully about domain design, maintainability, and the experience surrounding the product.

Before moving fully into software development, I spent more than seven years working in international project coordination and client-facing environments. That background still shapes how I work today: with ownership, organization, clear communication, and a collaborative mindset.

- Currently building **RetroBazar**, a modular e-commerce platform using hexagonal architecture and Spring AI
- Exploring **DDD, distributed systems, and AI-powered backend applications**
- Familiar with **C# and Unity** through a completed introductory game development course
- Based in **Barcelona, Spain**
